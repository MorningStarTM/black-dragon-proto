# assets/blender

Source .blend files for the semantic world (storefronts, signage, buildings).
Export target is glTF/GLB, referenced from sim/models — see design doc §4.2 for
why Collada is avoided and §4.3 for the visual-domain-gap check that should run
on a handful of rendered frames before committing to the full asset pipeline.

Status: not started. Phase 3 of the roadmap.
