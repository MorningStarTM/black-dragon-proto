# bd_swarm_coordination

Task handoff and deconfliction across drones (design doc §2.1). Mechanism is an
open question — decentralised multi-agent RL, a graph neural network, or a
simpler auction/consensus scheme (design doc §7).

Status: not yet implemented. Phase 6 of the roadmap, after the single-drone
VLM+RL pipeline is demonstrated end to end.
